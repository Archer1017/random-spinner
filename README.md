# 四人随机转盘

在四个匿名参与者之间随机抽选的转盘工具。

本仓库保存经过脱敏的源码快照，属于开发原型。

## 功能

- 四人随机转盘交互。
- uni-app与Vue页面原型。

## 运行

使用 HBuilderX 打开本目录，运行到 H5。主体 Vue 页面从历史开发代码恢复，补齐了被截断的末尾样式和最小项目入口，参与者均为匿名占位；抽选与动画仍需真机回归。

## 当前范围

已有Vue页面。

- 参与者展示采用匿名占位。

## 验证

Vue 页面、脚本与模板通过语法编译检查；未进行 HBuilderX 真机运行验证。

## 公开版说明

公开版不包含原聊天、私人账户数据、联系方式、服务凭证或旧 Git 历史。需要接口的功能使用自己的配置。第三方素材与依赖遵循其各自许可；本次整理未另行授予整体项目开源许可。
